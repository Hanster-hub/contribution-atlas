How XP works

2 XP per eligible author commit + 20 per merged PR + 2 per unmerged PR + 5 per unique PR reviewed by each reviewer, excluding their own PRs. Repeat submissions earn no extra XP; the earliest eligible submission sets the review date. Merging replaces the 2 unmerged XP with 20. Merge commits, the initial import and release bundles earn no XP. Commit and PR points are separate activity types.

Ranks use all-time XP and fixed thresholds above. Last 7 days uses seven UTC calendar dates ending at the snapshot timestamp. XP is a fun view of recorded activity, not effort, impact, or professional qualifications.
